# 概述
该项目为chisel语言第一个risc-v项目，目的是为了了解chisel语法，并了解risc-v架构基本原理，并熟悉risc-v在设计、验证阶段所有流程。
# Docker使用
为减少不同架构芯片带来的环境差异，risc-v的开发环境采用docker实现。docker基础镜像为官方ubuntu22.04版本，并加载linxu常用开发工具链以及开发库等，具体如下：

- RISC-V GNU Toolchain是一套针对 RISC-V 架构的开源编译工具链，包含编译器、汇编器、链接器、调试器等核心组件，用于将 C/C++ 等高级语言代码编译为 RISC-V 架构可执行的机器码。它是 RISC-V 软件开发的基础工具，广泛应用于嵌入式系统、操作系统内核、应用程序等开发场景

RISC-V GNU Toolchain 主要包含以下关键工具：

1. **GCC (GNU Compiler Collection)**  
    RISC-V 版本的 GCC 编译器，支持 C、C++、Fortran 等语言，负责将源代码编译为 RISC-V 汇编代码。
    
2. **Binutils**  
    二进制工具集，包括：
    - `as`：RISC-V 汇编器，将汇编代码转为机器码；
    - `ld`：链接器，将多个目标文件链接为可执行程序或库；
    - `objcopy`/`objdump`：目标文件处理工具（格式转换、反汇编等）。
3. **GDB (GNU Debugger)**  
    RISC-V 架构的调试器，支持程序断点调试、内存查看、寄存器监控等功能。
4. **Newlib / Glibc**  
    C 标准库实现：
    - Newlib：轻量级库，适合嵌入式系统（资源受限场景）；
    - Glibc：功能完整的 GNU C 库，适合通用计算场景。
5. **QEMU (可选)**  
    常搭配使用的 RISC-V 模拟器，可在 x86 等非 RISC-V 主机上运行编译好的 RISC-V 程序。
